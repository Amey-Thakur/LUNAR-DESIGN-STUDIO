## About

**Lunar Design Studio** is a professional portfolio website for architects and interior designers, showcasing 3D modeling, rendering, visualization, and design services.

Created for **Architect Mugdha Thakur**.

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Libraries**: jQuery, Slick Slider, Anime.js, Bootstrap 4
- **Icons**: FontAwesome 5
- **Fonts**: Open Sans (Google Fonts)
- **Deployment**: GitHub Pages
