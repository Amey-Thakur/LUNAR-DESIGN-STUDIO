## Vulnerability Reporting Protocol

In accordance with established professional standards for security disclosure, security-related observations associated with this project are documented through formal channels.

To document a security concern, communication is facilitated with the project creator:
  - **Creator**: [Amey Thakur](https://github.com/Amey-Thakur)
  - **Method**: Reports are submitted via the repository’s [GitHub Issues](https://github.com/Amey-Thakur/LUNAR-DESIGN-STUDIO/issues) interface to formally record security-related findings.

Submissions include:
  1. A precise description of the identified issue.
  2. Demonstrable steps or evidence sufficient to contextualize the finding.
  3. An explanation of the issue’s relevance within the defined scope of the project.
